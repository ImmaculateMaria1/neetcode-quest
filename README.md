# ⚡ NeetCode Quest

A fun, ADHD-friendly focus dashboard for working through the **NeetCode 150**.

**▶ Live:** https://immaculatemaria1.github.io/neetcode-quest/

## What it does

- **One problem at a time.** The focus card shows only the problem you're on, with a link to open it on LeetCode.
- **Small steps.** Six checkboxes break each problem down: read it twice → write 2 examples → say the brute force → find the pattern → code it → test edge cases.
- **Flexible focus timer.** Start with "Just 5 min", or pick 15, 25 or 45 minutes. When a session ends, it suggests a short movement break.
- **"I got distracted — I'm back!"** You get XP for coming back. Drifting is normal.
- **Brain dump.** Park stray thoughts with one keypress and get back to the problem.
- **Spin the wheel.** It picks an unsolved problem when you can't decide.
- **Hyperfocus mode.** Hides everything except the problem and the timer.
- **Levels, XP, streaks, daily goal, badges, confetti 🎉**
- **Revisit queue.** Problems you solved with help come back 3 days later.
- **Roadmap.** All 150 problems grouped by topic, with progress bars.

### Keyboard shortcuts

| Key | Action |
| --- | --- |
| `Space` | Start / pause timer |
| `D` | I drifted (and I'm back) |
| `B` | Brain dump |
| `Esc` | Exit hyperfocus mode |

## Run it

It's a single HTML file with no build step and no dependencies. Open `index.html` in a browser, or use the GitHub Pages link above.

## Your data

Progress is stored in your browser's `localStorage`. To move it to another device or keep a backup, use **Wins → Copy backup code** and **Restore from code**.
